# DA-10 — A/B Testing & Experiment Analytics

Portfolio-grade experimentation analytics focused on statistically defensible A/B testing, effect estimation, uncertainty, and decision-ready experiment conclusions.

## Planned scope

- Real/public randomized experiment data
- Experiment integrity checks
- Control vs treatment retention analysis
- Absolute and relative lift
- Confidence intervals and hypothesis tests
- Effect size and practical significance
- Power / minimum-detectable-effect discussion
- Multiple-testing and p-hacking guardrails
- Robust engagement diagnostics
- Reproducible Python pipeline
- Tests and GitHub Actions CI

> Full development will happen on a dedicated branch before final review and merge.
